## Typography

### Font Families

| Font | Type | Use |
|------|------|-----|
| **Playfair Display** | Serif | Headlines, titles, display text |
| **Inter** | Sans-serif | Body text, UI elements, labels |

### Font Weights

- **Playfair Display:** 400 (Regular), 500, 600 (SemiBold), 700 (Bold)
- **Inter:** 400 (Regular), 500 (Medium), 600 (SemiBold), 700 (Bold)

### Usage Guidelines

| Element | Font | Weight | Style |
|---------|------|--------|-------|
| Page titles | Playfair Display | Bold (700) | Normal |
| Section headings | Playfair Display | SemiBold (600) | Normal |
| Body text | Inter | Regular (400) | Normal |
| Labels/captions | Inter | SemiBold (600) | ALL CAPS, letter-spacing 0.1em |
| Buttons/CTAs | Inter | SemiBold (600) | Normal |

## Brand Voice

**Tone:** Warm, direct, and grounded. Like a thoughtful friend who happens to know a lot about systems.

**We are:**
- Clear
- Human-centered
- Curious
- Practical

**We're not:**
- Corporate-speak
- Preachy
- Jargon-heavy
- Cold

**Signature phrases:**
- "Bringing context back"
- "When systems stop seeing people"
- "Not to dismantle systems, but to help them keep working"
